    💡 How to Use

    1. Select a month from the dropdown.

    2. Fill Income, Expenses, and Savings in each tab.

    3. Use Scan to snap invoices and auto-add expenses.

    4. Check the Invest tab for suggestions based on your surplus.

    5. Use Payslip to break down your salary components.

    6. Data auto-saves. Use Export/Import to backup or transfer.

    🔄 Updating the App

    How updates work:

    1. You edit code → push to GitHub → Pages updates in 1-2 min

    2. The app checks for updates automatically

    3. When an update is found, a "🔄 Update Available" badge appears

    4. Tap the badge to reload with the new version

    Important: Always bump the version number in sw.js when you make changes!
